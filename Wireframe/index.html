Developer Basics

A quick introduction to three tools every developer uses: README files, wireframes and Git branches.

What is the purpose of a README file?

A README is a text file, usually called README.md, in the main folder of a project that explains what the project is and how to use it. It is often the first thing people see, because GitHub shows it on the repository's front page. A good README explains what the project does, how to install and run it, and how others can contribute.

What is the purpose of a wireframe?

A wireframe is a simple sketch of a page's layout. It shows where things like headings, images and buttons will go, without colours or final design. It helps designers, developers and clients agree on the structure early, while changes are still quick and cheap, so there's less guesswork and rework once coding starts.

What is a branch in Git?

A branch is a separate line of work in a Git repository. It lets you build a feature or fix a bug without changing the main version of the code, and several people can each work on their own branch at the same time. When the work is ready, the branch is merged back into main, usually through a pull request.
